# Hospital Queue Management (Mini System)
Plain HTML/CSS/JS + Supabase. No build step.

1. Supabase: create project → SQL Editor → run `supabase/schema.sql`
2. Put your Project URL + anon key in `js/config.js`
3. Open the folder in VS Code → run with **Live Server** (open `index.html`, and `display.html` on a second tab/screen)
4. `git init`, commit, push to GitHub (deploy free with GitHub Pages or Vercel)
